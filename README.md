# Juncheng Wang Academic Website

A lightweight, English-language academic website.

## Files

- `index.html` — homepage
- `research.html` — research directions
- `publications.html` — publication list and citation card
- `assets/styles.css` — all design styles
- `assets/site.js` — copy-citation interaction

## Personal details to update

Search the HTML files for these items and edit as needed:

1. Current role or degree status in the homepage biography.
2. GitHub.
3. Research descriptions before making unpublished project details public.
4. Future publications can be added by duplicating the `<article class="publication">` block in `publications.html`.

## Publish with GitHub Pages

1. Create a public GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload all files and folders from this directory.
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/root`.
5. Your site will appear at `https://YOUR-USERNAME.github.io`.

No build step or framework is required.
